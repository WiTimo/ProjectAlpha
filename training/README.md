# Phase 1 – Python Validation

This directory contains a lightweight validation pipeline for Phase 1 (Group A) features. It loads the
Parquet outputs emitted by the Rust preprocessing crate, performs the QA checks from `IMPLEMENTATION.md`,
standardizes the features using train-only statistics, and trains a tiny Temporal Convolutional Network
(TCN) as a smoke test. Metrics are logged for the validation and test segments so regressions can be
spotted quickly.

## Quick start

```bash
cd training
python -m venv .venv
. .venv/Scripts/activate  # or source .venv/bin/activate on Linux/macOS
pip install -r requirements.txt
python phase1_tcn.py --feature-root ../data/preprocessed/training --label-root ../data/preprocessed/training \
    --resolution fast --limit-files 4 --sequence-len 32 --epochs 5
```

The script accepts several switches:

- `--feature-root`: Root directory that contains the resolution subdirectories generated by preprocessing.
- `--label-root`: Directory with the per-file label Parquet outputs.
- `--resolution`: Which resolution folder to load (`fast`, `mid`, `slow`).
- `--limit-files`: Optional cap on how many Parquet files to load (defaults to 4 for speed).
- `--sequence-len`: Temporal window length (in bars) fed into the TCN.
- `--epochs`: Number of training epochs.

All logging is printed to stdout so it can be captured in CI or a notebook. See `phase1_tcn.py --help` for the full list of options.
